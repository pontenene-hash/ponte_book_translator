# PONTE 写真補正・ChatGPT出力 v2.0

## まずはこの3ステップ
1. 「① 写真を入れる」で写真・PDFをまとめて選び「写真を取り込む」。
2. 「② 補正を確認」で「向き・傾きをまとめて自動補正」。横向きや逆さが残ったら「左回転」「右回転」「上下反転」。文字・図の端が欠けていないか確認して「この写真でOK → 次へ」。
3. 「③ ChatGPT用に保存」でファイルを作り、PDFと依頼文をそれぞれ保存。この2ファイルをChatGPTへ添付します。翻訳結果をアプリへ貼り戻す操作は不要です。

### 湾曲が残ったら
「湾曲・切り取りを調整する」を開きます。「湾曲を伸ばす」では、赤・緑・青の各線を上・中央・下の文字の行に合わせます。丸い点を指で上下に動かし、下の仕上がりを確認して「この調整を使う」を押してください。写真全体が画面に収まらない場合は画面をスクロールして調整できます。
「紙の四隅を合わせる」では4つの点を紙の角へ動かします。間違えた場合は「取り込み時に戻す」で最初の写真に戻せます。
湾曲補正は文字の行の上下方向の変形を伸ばします。隠れた文字、折れ目、綴じ目の横方向の圧縮を完全に復元する機能ではありません。

### 横向き・上下逆への対応
読み込み時に写真のEXIF情報を反映します。自動補正では端末内／サーバー内のTesseractで文字の向きを検出し、確信度が低い場合は回転せず確認を求めます。画像の縦横サイズだけでは判断しません。文字が少ない表紙や図の多いページでは手動の回転ボタンを使ってください。画像を外部のAIへ送信しません。
Streamlit Cloudでは、同梱の `packages.txt` を `app.py` と同じ階層にアップロードしてください。WindowsでTesseractを別途導入していない場合もアプリは使えますが、自動の文字方向判定は行わず回転ボタンで調整します。

## いま使っているアプリの更新
1. いまのアプリで「途中保存」をダウンロードしてください。
2. このZIPを展開します。
3. GitHubの同じリポジトリに、展開した `ponte_book_translator` フォルダーの**中身をすべて上書き**します。`simple_app.py`、`orientation.py`、`packages.txt` と `curve_editor/index.html` も必須です。`app.py`だけの更新では動きません。
4. 更新が反映されたアプリを開き、画面に「v2.0」と3ステップがあるか確認してください。
5. 「途中保存・再開／本の名前・用語辞書」から保存した `.ponte` を読み込めます。
ZIPをダウンロードするだけでは、稼働中のアプリは更新されません。

閉じる前に「途中保存」を保存してください。総ページ数は完成PDFに表示せず、原本の印刷ページ番号を使用する依頼文を出力します。
以前の翻訳・編集機能が必要な場合はサイドバーの「従来の翻訳・編集画面を使う」をオンにできます。

# PONTE 洋書翻訳ノート v1.3.1（PDF＋ChatGPT依頼文出力対応）

写真やPDFを順番に読み込み、左に原本、右に日本語を並べて確認・出力するStreamlitアプリです。

## 最後にPDFとプロンプトを一緒に出力する

補正と確認が終わったら「一括補正・画像出力」の最後で「PDF・プロンプト・画像ZIPを作成」を押してください。

- `corrected_pages.pdf`：選んだページだけを現在の順番で収録した補正済みPDF。
- `ChatGPT_prompt.txt`：同じPDFのページ対応表・プロジェクト名・用語辞書を反映した依頼文。
- `ChatGPT_handoff.zip`：上記2点をまとめたZIP。展開してPDFとTXTをChatGPTへ添付します。
- `corrected_images.zip`：画像として送る場合の予備データ。画像PDFを読み取れない環境では展開したJPGを添付します。

ChatGPTへ2ファイルを添付し、**「添付の依頼文に従って、翻訳と対訳PDFの作成を進めてください」**と送信します。TXTを添付せず、「作成した依頼文を確認・コピー」から文章をコピーしてメッセージ欄へ貼り付ける方法もあります。

初回はこの2点で開始します。続きの場合は、前回の統合版PDF・用語辞書・作業記録も添付してください。完成ファイルの自動引継ぎやChatGPTへの自動送信は行いません。

ページの順番・対象ページ・用語辞書・プロジェクト名を変えたら、作成ボタンをもう一度押し、PDFと依頼文を必ず同じセットで使ってください。出力済みの古いPDFと新しい依頼文を混ぜないでください。

アプリで書き出すPDFは画像のみで、OCRテキストはありません。ChatGPTの環境や利用できるツールによって画像PDFを読める範囲が異なるため、依頼文には「画像として読めなければJPGを求める」「未処理ページを完成扱いにしない」という指示を含めています。完成品質や一度に処理できる量を保証するものではありません。

## 今回の使い方：アプリで一括補正 → ChatGPTで翻訳・出力

1. 「1　資料を追加」で写真・PDFをまとめて読み込みます。
2. 「一括補正・画像出力」を開きます。
3. 処理枚数を選び、「未処理ページの補正候補をまとめて作る」を押します。傾き・台形を順番に処理します。検出できない四隅は無理に切り出さず、画像全体を保持します。
4. 5ページずつ表示される一覧で、文字や図が切れていないか確認します。「表示範囲」を変えると次の5ページを見られます。
5. 良い候補は個別に採用できます。全候補を確認した場合はチェックを付け、まとめて採用できます。確認せず採用しないでください。
6. 湾曲や枠のずれがあるページは「湾曲・四隅を個別に調整」を押します。調整・採用後、メニューから一括画面へ戻ります。古い候補が残っている場合は破棄してください。
7. 補正しなくてよいページは、候補を破棄し「現在の画像を確認済みにする」を押します。
8. ページの上下移動で順番を確認します。
9. 「PDF・プロンプト・画像ZIPを作成」を押し、どちらもダウンロードできます。
10. ChatGPTへ画像として渡す場合はZIPを展開し、`page_0001.jpg` から順に添付します。PDFは画像のみで、OCRテキストは含みません。
11. 作業を閉じる前に「途中保存」を保存します。採用済み補正・元画像・画像確認状態を保持します。**未採用候補は途中保存に含まれず、次回作り直します。**

一括補正は課金APIを使いません。自動の湾曲判定は含まず、ページごとの詳細調整で対応します。エラーのページは元画像を保持し、他のページを処理します。上限150ページまで複数回に分けて進められます。初めてなら5〜10ページで試してください。

### 湾曲の詳細補正

個別補正の「湾曲の詳細補正：文字行に合わせる」を開いて有効にします。

- 画像の上部・中央・下部から、できるだけ長く続く文字の行を1本ずつ選びます。
- 表の5列は左端・幅25%・中央・幅75%・右端です。それぞれの位置で、選んだ行の下端が画像の上から何%にあるかを指定します。
- 「基準線の重なりを確認」で、赤・緑・青の線を画像に重ねます。線が文字の行の下端に沿うように少しずつ調整してください。
- ページの余白部分は、文字行の曲がりを左右へ延長して設定します。
- 「補正結果をプレビュー」で確認してから採用します。各列で赤→緑→青の順を守り、線が交差しないようにします。
- 詳細補正は、台形・傾き補正後の画像に適用します。有効な間は簡易補正の上下スライダーを使いません。
- 左右で違う曲がりや非対称な波形を調整でき、上下の画像端も保持します。ただし、綴じ目で隠れた文字の復元や、3D形状からの厳密な横方向伸縮補正は行いません。

## 最初に知っておくこと

- **このZIPはアプリ一式です。ZIPを開くだけでiPhone上で動くものではありません。** Windowsで起動するか、GitHub経由でStreamlit Community Cloudへ配置してください。
- 自動翻訳には **GeminiまたはOpenAIのAPIキー** が必要です。利用料金や無料枠、制限は提供元のアカウントで確認してください。無制限・完全無料の自動翻訳を保証するものではありません。
- キーがなくても「手動（APIなし）」で、ChatGPTなどで訳した文章を貼り付けてPDF・Wordを作れます。
- 最初は同梱の操作デモか、原書1ページで確認してください。
- アプリのコード・ローカル機能は検証済みです。利用者のAPIキーを用いた翻訳と、本人のGoogle認証を用いた直接出力は、この納品時点では未実行です。

## 追加料金なしで使うには

写真補正、ページ整理、翻訳文の手動編集、PDF・Word作成にはAPIを使いません。自分のWindows PCで起動すれば、これらの処理にAPI利用料やアプリ独自の料金はかかりません（端末・通信などは別）。

翻訳方法は次の2つです。

- **API料金なし**：既定の「手動（APIなし）」を使い、ChatGPTなどで翻訳して貼り付けます。利用するチャット側の契約・回数制限はそのまま適用されます。
- **無料枠内で自動翻訳**：Geminiの無料枠が使えるアカウント・モデル・APIキーを使います。回数・容量などの上限があります。Google AI Studioで利用区分を確認し、無料利用だけを希望する場合は有料枠へ切り替えないでください。アプリがAPIキーから課金区分を保証する機能はありません。

無料枠の対象・制限は提供元で変更されることがあります。公式料金表：https://ai.google.dev/gemini-api/docs/pricing

このアプリには、自動で課金設定を有効にする処理、制限到達時に有料サービスへ切り替える処理はありません。

## 写真の傾き・曲がりを補正する

1. 資料を追加し、左のメニューから **「写真の補正（無料）」** を開きます。
2. 補正するページを選び、「ページの四隅を自動検出」を押します。
3. 緑の枠が紙の外周に合うか確認します。違う場合は、左上・右上・右下・左下の横位置・縦位置を調整してください。検出できない場合は画像全体の枠から調整できます。
4. 「文字・罫線から小さな傾きを自動補正」を必要に応じて使います。誤検出する場合はオフにし、傾きのスライダーを動かしてください。横向きの写真は90度単位でも回転できます。
5. 本のページの行が弓なりの場合は「本のページの湾曲を調整」を開きます。行の中央が下へたわんでいるなら＋、上へ膨らんでいるなら−へ少しずつ動かします。上部と下部で別の量を指定できます。
6. 明るさ・コントラストを必要に応じて調整します。
7. **「補正結果をプレビュー」** を押し、補正前後を比較します。
8. ページ端や文字・図が欠けていなければ **「この補正を採用する」** を押します。
9. 採用した画像を翻訳・図の切出し・PDF/Word出力に使用します。元画像も途中保存ファイルに残ります。

補正後も「補正前の画像に戻す」を押せます。再調整は常に補正前の画像から行うため、何度も加工して画質が劣化するのを避けます。残す元画像は取り込み時に向き補正・縮小した画像であり、撮影ファイルの原寸データではありません。

**先に写真を補正してから翻訳する順番が基本です。** 翻訳後に補正を採用・解除すると、本文は残しますが確認状態を「要確認」に戻し、図の座標と過去の編集履歴はリセットします。画像と図の位置がずれたまま出力することを防ぐためです。

### 補正できる範囲

| 写真の状態 | 対応 |
|---|---|
| 少し傾いている | 自動傾き候補＋手動微調整 |
| 斜めから撮影して台形になっている | 四隅の指定から長方形に補正 |
| ページの行が緩く弓なりになっている | 上下の湾曲量を手動調整する簡易補正 |
| 暗い・全体のコントラストが弱い | 明るさ・コントラスト調整 |
| 複雑に波打つ・綴じ目が強く潰れている | 完全な補正はできない場合があります |
| 指で隠れている・ピンぼけ・紙の外側が写っていない | 見えない情報の復元はしません。撮り直してください |

湾曲を立体的に自動推定する製本スキャン機能ではありません。詳細補正は文字行に合わせて3本×5点を手動調整します。図や写真の形も変わるため、必ず補正結果を確認してください。一括補正候補は一覧確認後にまとめて採用できます。

5. 初回は必要なライブラリがインストールされます。数分かかることがあります。
6. ブラウザーにアプリが開きます。開かなければ `http://localhost:8501` にアクセスしてください。
7. 黒い起動画面は、利用中は閉じないでください。終了は起動画面で Ctrl+C です。

Pythonを自分で管理している場合：

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Mac/Linuxでは `.venv/bin/activate` を使用してください。

### 個人用にする

個人利用なら公開範囲を限定してください。追加のアプリパスワードも設定できます。Streamlitのアプリ設定のSecretsに、次のように登録します（ご自身の長いパスワードへ変更）。

```toml
APP_PASSWORD = "ここを自分だけの長いパスワードに変更"
```

APIキーはアプリの画面に毎回入力できます。個人用アプリだけで、入力を省略したい場合はSecretsへ登録します。

```toml
GEMINI_API_KEY = "ご自身のGeminiキー"
# OpenAIを使う場合だけ設定
OPENAI_API_KEY = "ご自身のOpenAIキー"
```

**キーを設定したアプリを他人へ開放すると、その人も設定済みのキーで翻訳できます。** 個人利用の範囲に限定してください。SecretsはGitHubのコードやREADMEへ貼り付けません。

## 4. 自分の洋書を翻訳する

### 資料を追加

- JPG・JPEG・PNG・PDFを複数選び、「選んだ資料を追加」を押します。
- 1ファイル50MB以内、1プロジェクト150ページ以内。長い本は章ごとに分けると管理しやすくなります。
- PDFは全ページを取り込みます。暗号化PDFは解除したコピーを用意してください。
- 原本はページ画像として保存します。写真はEXIFの向きを補正し、最大2400×3200pxに縮小してJPEGへ変換します。元ファイルの完全保存ではないため、オリジナルは別途保管してください。
- iPhoneのHEICには直接対応していません。JPEGまたはPNGで保存してください。
- 同じ名前・同じ内容の資料は同一セッションで二重追加しません。途中保存の読込後は追加済み判定がリセットされるため、重複追加に注意してください。

### APIで翻訳

1. 左側の翻訳方法をGeminiまたはOpenAIへ切り替えます。iPhoneでは画面上部のサイドバーを開きます。
2. ご自身のAPIキーを入力します。
3. モデルIDを確認します。既定値はGeminiが `gemini-2.5-flash`、OpenAIが `gpt-4.1-mini` です。利用できない場合は、ご自身のアカウントで利用可能な**画像入力・JSON出力対応モデル**へ変更してください。
4. まず「このページを翻訳」を押します。
5. 良ければ「未翻訳ページを順番に自動翻訳」を開き、今回の処理枚数と待ち時間を設定して実行します。
6. 一度の実行は最大30ページです。何回でも続けられ、訳文が入力済みのページはスキップします。
7. 実行中はタブを開いたまま待ってください。iPhoneの画面ロックや接続切断で長い処理が止まることがあります。最初は1〜5ページずつがおすすめです。

翻訳を押すと対象ページの画像、用語辞書、追加指示が選んだAIサービスへ送られます。APIのエラーや応答打ち切りを成功扱いせず、元の訳文を保持します。自動リトライや別サービスへの自動切替は行いません。タイムアウト後の再実行は重複課金になり得るため、提供元の利用状況を確認してください。

### APIを使わない場合

1. 「手動（APIなし）」を選択します。
2. ページの「原本画像を保存」を押します。
3. 「APIなし：ChatGPTで翻訳して貼り付ける」を開きます。
4. 画像と表示された指示文をChatGPTに送ります。
5. 日本語の回答を「日本語訳（全文）」へ貼り付け、保存します。
6. JSON形式で回答された場合は、専用欄に貼り付けて「翻訳回答を読み込む」を押します。英文・訳文・図の範囲をまとめて反映します。

### 確認と修正

- 原書ページ番号、見出し、本文、読取英文、メモを編集して「編集を保存」を押します。
- **ページやメニューを切り替える前に、編集を保存してください。** 入力中の未保存変更は保存データに含まれません。
- 原本と照合したページにだけ「確認済み」を付けます。AIによる図の範囲や専門用語も確認してください。
- 再翻訳には置換のチェックが必要です。編集・翻訳の直前の状態を最大5件保持します。
- 「前へ」「後ろへ」または移動先番号で順番を変更できます。
- 用語辞書は「英語 → 日本語」を1行ずつ登録します。辞書更新は以降の翻訳へ適用され、既存ページの訳文は勝手に変えません。必要なら再翻訳します。

### 図・写真

- 原本側の図・写真はそのまま残ります。
- AIが検出した領域を切り出し、日本語側の冒頭に元の上下順で再配置します。
- 図中の英文を消して日本語へ置き換える機能ではありません。日本語訳の中にラベル対応表を作るよう指示しています。
- 自動検出がずれた場合は「図・写真を日本語側にも掲載する」のJSON座標を修正できます。
- 座標は `[左,上,右,下]`。画像全体の左上が `[0,0]`、右下が `[1000,1000]` です。
- 例：中央上部の図を切り出す場合 `[{"box":[100,100,900,400],"caption":"図の説明"}]`。
- 日本語側は読みやすく再配置する方式です。原書と完全に同じ組版は行いません。写真の傾き・台形と簡易湾曲補正は「写真の補正（無料）」で調整できます。

## 5. 途中保存・再開

- ページの取込、翻訳の完了、編集保存のたびにセッション内とサーバーの一時領域へ保存します。
- **閉じる前に「途中保存をダウンロード」を押し、`.ponte` ファイルを自分の端末へ保存してください。** 原本画像・補正前画像（補正済みの場合）・翻訳・辞書・順番・編集履歴が入ります。APIキーとGoogle認証情報は含みません。
- 次回は「1　資料を追加」の「途中保存ファイル」から読み込み、「保存データを開く」を押します。
- セッション終了後にサーバーの一時ファイルを自動検索して復元する機能はありません。共有ホスティングの再起動でも一時ファイルは消え得ます。`.ponte` を持っておくことが継続利用の基本です。
- プロジェクト名は変更できますが、ダウンロード名は固定です。章名・日付を付けて端末側で整理してください。

## 6. 出力形式

| ファイル | 内容 |
|---|---|
| `facing_pages.pdf` | 1枚の横長ページに左＝原本、右＝日本語。閲覧アプリの設定によらず比較できます。 |
| `alternating_pages.pdf` | 原本→日本語の順の縦A4。最初を左ページとする見開き設定を付けています。閲覧アプリによって設定が反映されない場合があります。 |
| `japanese_only.pdf` | 日本語ページのみ。図の掲載は出力設定で選択。 |
| `translation.docx` | 原本画像ページと編集可能な日本語文章。Google Docs取込用にも使えます。 |
| `translation.txt` | 日本語テキスト。 |
| `translation_exports.zip` | 上記5ファイルを一括でまとめたもの。途中保存ファイルは別途保存してください。 |

長文が1ページに収まらないときは続きのページを追加します。見開き・交互PDFでは、続きにも同じ原本を再掲して対応を保ちます。訳文を切り捨てたり、極端に縮小したりしません。日本語フォントはPDFへ埋め込みます。

出力ボタンを押したあと、各ファイルを続けてダウンロードできます。編集や出力条件の変更後は作成ボタンを再度押してください。

## 7. Googleドキュメント

### 一番簡単な方法

1. アプリからWordをダウンロードします。
2. Google Driveへアップロードします。
3. パソコンのDriveでファイルを開き、「Googleドキュメントで開く」を選びます。
4. 必要に応じて「Googleドキュメントとして保存」します。

PDFの左右配置はGoogle Docsでは完全再現しません。Google Docsは文章の編集・検索用、見開きPDFは固定レイアウトでの閲覧用です。

### アプリから直接作る方法

同梱の `GOOGLE_SETUP.md` を参照してください。初回はご自身のGoogle CloudでOAuth認証を設定します。認証後、アプリの出力欄にあるボタンから**新しい文書**を作れます。既存Google Docsへの追記・更新には対応していません。

## 8. よくある困りごと

- **自動翻訳ボタンが押せない**：手動モードになっていないか、APIキーが入力済みか確認。
- **401/403**：キー・API有効化・モデルの利用権限を確認。
- **404**：モデルIDを変更。提供終了やアカウントの対応状況は提供元で確認。
- **429**：回数制限・利用枠・残高等を確認。処理枚数を減らし、待ち時間を延長。
- **翻訳が長すぎて完了しない**：ページを分割するか、十分な出力上限に対応したモデルへ変更。
- **日本語側の図に本文が混ざる**：図の範囲を修正するか、日本語側への図の掲載をオフ。
- **更新した辞書が昔の翻訳に反映されない**：既存訳文は保持します。必要なページだけ再翻訳。
- **画面が初期状態になった**：ダウンロードした `.ponte` を読み込み。
- **PDFが重い**：章ごとに分ける。日本語側の図をオフにする。
- **Streamlitでファイルが見つからない**：GitHubの実際の階層とMain file pathを確認。
